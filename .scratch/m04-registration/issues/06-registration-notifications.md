# 06 — 报名成功与候补递补通知（NOTIFY-01）

**What to build:** 报名确认与候补递补在业务提交后异步落站内信，递补者无需刷新就能知道结果。

**Blocked by:** 01 — 报名与候补主流程；02 — 取消报名与自动递补；03 — 管理员移除报名与递补

**Status:** ready-for-agent

- [ ] 读需求 NOTIFY-01/05、01 §4.10、03 §5.3、04 §5.22。
- [ ] 新增 `REGISTRATION_CONFIRMED`、`WAITLIST_PROMOTED` 事件类型；报名确认、取消/移除/注销触发递补时，在同一业务事务写 Outbox。
- [ ] 仅新报名且 CONFIRMED 发“报名成功”；WAITLISTED 不发。
- [ ] 递补事件只发给被递补者本人；被取消/移除者不发通知。
- [ ] 通知消费者按事件 ID 去重，写 `notification`：`type=0/1`、`ref_type=MATCH`、`ref_id=matchId`，标题与内容不含手机号等敏感信息。
- [ ] 取消、管理员移除、P-05 注销三条递补路径行为一致。
- [ ] 实时逐条发送，不聚合、不免打扰（NOTIFY-05）。
- [ ] 不新增同步写通知表的调用；通知只经 Outbox → Kafka → 消费者。
- [ ] 测试：确认报名通知、候补报名不发、取消递补通知、移除递补通知、注销递补通知、重复投递不重复、内容脱敏。
