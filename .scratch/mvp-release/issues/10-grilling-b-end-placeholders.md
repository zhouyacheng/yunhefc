# 10 — B 端占位页最小交付范围

Type: grilling
Status: resolved
Blocked by: 01, 09

## Question

基于交付缺口盘点，确定 B 端占位页的最小交付：

- `players`、`roles`、`invites`、`dashboard` 各自是否首批上线；`audit` 与 `settings` 分别由 08 / 06 定。
- 每页的字段、操作与后端已有接口的对应关系；缺接口的项是否补。
- dashboard 是否保留或下线。
- 目标是满足 112 条 MVP 可演示的最小页面，不做视觉改版。

事实指针：01 答案、02 后台页面、05 §3.1/§3.3/§3.13、`frontend/packages/permissions` 的 `ADMIN_SECTIONS`、`SectionPage.vue`。

## Answer

### 1. 页面范围

- **B07 球员、B08 角色权限、B11 邀请管理三页全进首批**，按 02 §6.9 / §6.10 / §6.13 全量实现；后端 PLR/AUTH/ROL/INV 接口已齐，不新增接口。
- B09 系统设置与 B10 操作日志分别由 06 / 08 号票定，不在本票范围。

### 2. B01 工作台

- **本期下线**。需求 MVP 范围（§4.1）与 112 条验收均无工作台；「今日操作数」依赖 AUD-01，属纯增项。
- `ADMIN_SECTIONS`、后端 `AuthService.sections`、02 站点地图/导航/页面表同步移除 `dashboard`；`/admin` 与登录后落到**首个有权限分区**，不固定跳比赛管理，避免仅有 `role:view:any` 等非比赛权限的角色落 403。
- 02 §6.3 标为「二期，本期下线」，06 §45 记决策。

### 3. 页面 → 接口映射

| 页面 | 操作 | 接口 |
|---|---|---|
| B07 | 列表、筛选、排序、分页 | PLR-05 |
| B07 | 编辑档案（号码/姓名/地区/位置/副位置/星级） | PLR-06 |
| B07 | 审核通过 | PLR-07 |
| B07 | 外挂转正 | PLR-08 |
| B07 | 注销 | PLR-09 |
| B07 | 换绑手机号 / 解绑微信 | AUTH-11 / AUTH-12 |
| B08 | 角色与权限读取 | ROL-01 / ROL-06 |
| B08 | 角色新建 / 改名 / 删除 | ROL-02 / ROL-03 / ROL-04 |
| B08 | 权限勾选保存 | ROL-05 |
| B08 | 用户选择（姓名/手机号） | AUTH-13（新增 `keyword`） |
| B08 | 用户角色分配 | ROL-07 |
| B11 | 列表 | INV-04 |
| B11 | 创建入队/比赛邀请并返回 `inviteUrl` | INV-05 |
| B11 | 撤销 | INV-06 |

高风险写操作沿用 `newIdempotencyKey()`；角色分配/权限保存、审核/转正/注销、创建/撤销邀请均带幂等键。

### 4. 头像与 OSS 边界

B07 首批只展示头像与已有 `avatarUrl`，编辑弹窗不提供上传；FIL-01/02 随 OSS 批次（15 号票）落地后再补入口，不阻塞 B07。

### 5. B11 复制链接的契约冲突

`invite_link.token_hash` 只存哈希，05 §4 明确 `Invite` 列表不返回 token。因此：

- 复制只在**创建成功弹窗**提供（INV-05 返回 `inviteUrl`）；
- 列表行只保留撤销；
- 02 §6.13 已据此收敛，不改 04 / `schema.sql` / 05，不新增重生成接口。

### 6. AUTH-13 keyword

- 新增可选 `keyword`：去首尾空格、空串不过滤、长度 >64 返回 `40001`；对 `player.name` 或 `app_user.phone` 模糊匹配。
- 不新增接口；05 §3.1 已更新。

### 7. 验收口径

三页各一条 Playwright 黄金路径：B07 筛选 + 编辑保存、B08 权限勾选保存、B11 创建 + 复制 + 撤销；最终清单由 19 号票汇总。
