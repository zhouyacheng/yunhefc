# 云河FC UI 关键页（按原型样式照搬）

本目录是 3 张关键页的静态视觉稿，直接复用原型 `prototype/` 的渲染结构与 `assets/css/style.css`，确保与原型视觉一致：

| 文件 | 页面 | 内容 |
|---|---|---|
| `index.html` | C 端首页 | 下一场比赛记分牌、报名队列、近期赛程、球队火力（二期占位） |
| `match.html` | 比赛详情 | 5 个 Tab、报名概况、事件统计、阵容预览、个人报名与管理员入口 |
| `admin.html` | B 端工作台 | 四组侧栏、KPI、下一场比赛、待处理、最近操作 |

## 运行

在仓库根目录启动静态服务：

```bash
python3 -m http.server 4180
```

访问 `http://localhost:4180/docs/design/ui/index.html`。

页面中指向赛程、球队、个人中心、登录的链接会跳转到 `prototype/` 对应页面（需要仓库根目录作为服务根）。

## 说明

- 页面由原型渲染结果导出为静态 HTML，样式与结构照搬原型。
- 在原型样式之上补充了 `assets/css/ui-extras.css`：
  - C 端移动端底部快捷栏（首页 / 赛程 / 球队 / 我的）。
  - 比赛详情第 5 个“分组”Tab；正式比赛显示不参与分组的空态。
- 比赛详情包含少量内联脚本，用于 5 个 Tab 的切换。
- “演示身份”“切换身份”等原型控件在此静态稿中不生效。
- `assets/` 下为原型样式、Logo、favicon 与补充样式。
